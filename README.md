### 🔬 Core Research & Mathematical Implementations

#### [Latent Graph Learning for Multimodal Disease Prediction](https://github.com/zeinabrahbar)
*   **Context:** Developed models to infer latent graph topologies directly from heterogeneous, unstructured clinical modalities.
*   **Methodology:** Integrated structural representation learning over non-Euclidean data matrices including structural MRI, functional fMRI, and irregular clinical diagnostic vectors.
*   **Evaluation:** Benchmarked generalization capabilities and topological convergence properties on **TADPOLE** and **ABIDE** datasets.

#### [Multimodal Graph-based Message Passing & VQA (M.Sc. Thesis)](https://github.com/zeinabrahbar)
*   **Context:** Addressed cross-modal fusion bottlenecks by mapping decoupled visual and textual semantic entities into a joint graph domain.
*   **Methodology:** Engineered localized structural learning layers to establish data-driven edge connections, leveraging GNN architectures for joint message propagation and multimodal reasoning.
*   **Evaluation:** Validated on the complex **VQA v2** benchmark.

#### [Frameworkless GCN with Random Weights](https://github.com/zeinabrahbar)
*   **Context:** Implemented an architectural study of Graph Convolutional Networks leveraging randomized weights directly from literature, where no public code baseline existed.
*   **Methodology:** Programmed the entire pipeline from basic linear algebra arrays using NumPy/PyTorch primitives without high-level wrappers (e.g., PyTorch Geometric). 
*   **Objective:** Mathematically validated local neighborhood smoothing, neighborhood aggregation steps, and the explicit representation properties of raw graph spectral filtering.
